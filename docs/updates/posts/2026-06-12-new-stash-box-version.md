We updated to the new version of stash-box, which brings some great new features. Highlighting some of the changes:

1. Major search rewrite - no longer limited to 10 results, ability to filter performers by gender, now considers disambigaution when searching for performers, and much more. If you find edge cases where search doesn't work as expected, [please report them to stash-box GitHub](https://github.com/stashapp/stash-box/issues){target=_blank}.
2. Entity URL parsing in search - can now search using internal URLs and UUIDs.
3. Move/delete fingerprints - moderators can now move or delete fingerprints from the UI.
4. Bra size field - bra sizes are now split into cup and band size fields.
5. MD5 hash removed - MD5 hashes have been removed from scenes.
6. Sort by popularity - can now sort scenes and performers by popularity. It works by number of people having submitted a scene/performer fingerprint for a given scene/performer.
7. Notification types - notifications are now categorized into types and have different urgency levels. 
8. Fingerprint cluster view - can now view scene fingerprints in a cluster view which groups similar fingerprints together.
9. Merge performers/tags - now merges all fields and presents conflicting data for review.
10. Lightbox view - can now view images in a lightbox view instead of carousel view.
11. Sort by duration - can now sort scenes by duration.
12. New notification type - new notification type for when your pHASH fingerprint is moved to a different scene.
13. Site categories - admins can now categorize sites into various categories to make browsing links easier.
14. Only parent networks toggle - can now toggle to only show parent networks in the studios list.
15. Parse UUIDs in comments - UUIDs in comments are now parsed and converted to internal links.
16. Sites menu - sites page is now accessible from the menu bar for everyone.

There are many other improvements and bug fixes which you can read about in the full release notes on GitHub.
