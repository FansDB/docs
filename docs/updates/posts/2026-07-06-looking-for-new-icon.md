As you may have noticed, we have changed our icon and added favicon to the site. Old icon was a raster image and wasn't really working well when scaled down. New icon is vector image and should scale better. However, we and some of you are not completely happy with it and so we are looking for a new icon.

We have a few requirements for the new icon:
1. It should be a vector image (SVG).
2. It should be simple and readable when scaled down to 16x16 pixels.
3. It should be compatible with dark and light themes.
4. It should be safe for work (no nudity, sexual themes, or other NSFW content).
5. You agree to release it under [CC0](https://creativecommons.org/publicdomain/zero/1.0/){target=_blank} so we can use it freely.

Submit your icon ideas to us at [FansDB icon submissions](https://discourse.stashapp.cc/t/fansdb-icon-submissions/11014){target=_blank}.
